# Lethal Client — Minecraft 1.21.11

Backport of the 26.2 client to Minecraft 1.21.11 (Java 21, Fabric Loom 1.14, Fabric Loader 0.17.3+, Fabric API 0.141.6+1.21.11).

- `LethalClient-1.21.11.jar` — current 1.21.11 build

Boots to the title screen with all features ported (custom sky, title scene,
scoreboard, fullbright, freelook/zoom, nametag logos, etc.). ProGuard-obfuscated,
same as the 26.2 build. Drop the jar into your `mods` folder.
