# Lethal Client — Minecraft 1.21.11

Backport of the 26.2 client to Minecraft 1.21.11 (Java 21, Fabric Loom 1.14, Fabric Loader 0.17.3+, Fabric API 0.141.6+1.21.11).

- `LethalClient-1.21.11.jar` — current 1.21.11 build (v1.0.277)

Feature parity with 26.2 (v1.0.277): custom sky, title scene, scoreboard,
fullbright, freelook/zoom, nametag logos, the reset auction mode, the themed
pay-confirm, and more. ProGuard-obfuscated with auto-update, same as 26.2.
Drop the jar into your `mods` folder.
